## 识别特征

- 文章页：`https://mp.weixin.qq.com/s?__biz=<biz>&mid=<mid>&idx=<idx>&sn=<sn>`；短链：`https://mp.weixin.qq.com/s/<短 id>`（需打开后解析，见 A8）。
- 历史消息页：`mp.weixin.qq.com/mp/profile_ext?...`（手机 UA 语境；桌面打开常见「请在微信客户端打开」，见 A5）。
- 配图：`mmbiz.qpic.cn` 域名（原图尺寸上限见 C7）。
- 页面为长文单页（正文垂直极长，2~4 万 CSS px 级，见「懒加载与长图实证」节），非 SPA 懒加载路由。
- ⚠ 具体 DOM 选择器（标题/正文容器/作者/时间/尾部导航）**本批未探针确认**——首次实弹采集前先按 references/playbook.md 定位方法论现场探针，勿照抄猜测 selector。

## 专属操作手法

（以下各节=wechat-mp 专属：入口 / 反爬 / 取文 / 配图 / 懒加载与长图 / 待复验）

### 采集入口：不能按号枚举，只能按文章链接（A5）

- **A5（观察性/未复验）**：桌面浏览器打开公众号历史消息页只能得到「请在微信客户端打开」提示页，**不能按公众号枚举历史文章**。
- 可行路径=**按文章链接逐篇采集**（外部给定文章 URL / 从已抓文章内互相引用的链接扩展）；不要尝试在历史消息页做翻页枚举（此路在桌面端封死）。
- 若确有批量按号需求：属已知能力边界，需另行验证（微信客户端自动化/其他通道），不在本手册承诺范围。

### 短链需打开后读 location.href 拿 `__biz`（A8）

- **A8（观察性/未复验）**：`mp.weixin.qq.com/s/<短 id>` 打开前 URL 中**不含** `__biz`；页面加载后 `location.href` 会被改写为带 `__biz=<biz>&mid=...&idx=...&sn=...` 的完整形式。
- 手法：navigate 到短链 → 等页面稳定 → `evaluate('location.href')` 取真实 URL → 从中解析 `__biz`（去重/去参后作为该号的文章标识键）。
- 同一公众号多篇文章的 `__biz` 相同，可据此归并文章到号（号名从页面正文/头部读，选择器待探针）。

### 反爬：数据中心 IP 全量验证（A10）

- **A10（观察性/未复验）**：出口为数据中心 IP 时，文章页可能要求**全量验证**（人机校验）后才能读正文——即不是抽样拦截，而是该 IP 下每篇都过验证。
- 现场症状=正文区被验证层替代/跳转验证页；此通道下自动化"一次通过后连续采集"的稳定性**未经本手册验证**（会话内为经验性观察）。
- 滑块类验证（A7）：**一次放行即继续，严禁刷新硬刷**——反复刷新会加重风控；拿不到放行就停手报告，不绕路试探。
- 处置纪律 = **SKILL 红线 #12 反爬/验证码处置纪律**（2026-10-21 落地：截图取证→最多一次「去验证」→转人工）＋ playbook §MCP 交互模式纪律「反爬/验证码处置」条；全程留证截图。

### 正文与尾部杂质（C5 / A6）

- **C5（观察性/未复验）**：文章尾部含杂质——「上一篇/下一篇」导航 + 公众号二维码/关注引导；入档前需**裁除**（正文容器内裁，勿整页直接存）。
- **A6（观察性/未复验）**：「上一篇/下一篇」**仅在合集（album）文章内出现**；非合集文章尾部没有该导航——裁除逻辑须按存在性条件化，不能假定每篇都有固定尾部结构。

### 配图原图与分辨率上限（C7）

- **C7（观察性/未复验）**：配图可拿到「原图」URL，但微信侧**原图宽度上限约 1080px**——这是平台压缩天花板，抓到最大原图仍可能糊，**无法靠改 URL 参数突破**。
- 因此：配图质量上限=1080px；验收标准按此设定，勿因"图糊"反复重试或猜参数（糊是物理上限，不是抓取姿势问题）。
- 原图 URL 与页面展示图 URL 的对应关系（选择器/属性）待现场探针；抓取走 `mmbiz.qpic.cn` 直连（是否需 Referer/UA 待验证）。

### 合规边界（robots.txt 与使用范围）

- `mp.weixin.qq.com/robots.txt` = `Disallow: /`（2026-10-20 竞品报告实测记录）——公开文章用于**内部竞品分析**属常见灰色地带，纪律：**仅内网留存 / 不二次公开 / 标注来源 / 控制访问频率**；对外发布前必须人工复核授权。

### 懒加载与长图实证（2026-10-21 全量 140 篇）

> F8/F9/F14/F15 = 他方并行采集会话实测（2026-10-21，全量 140 篇）；我方尚未实弹复跑，故状态仍 `stale`。

- **观察事实**（2026-10-21 竞品会话，观察性）：单篇长文可达 **2~4 万 CSS px**；整页截图 23805 CSS px 直接报 `Unable to capture screenshot`；47610px 超长单图在查看端被降采样；PNG 单图曾达 16MB；单页截图曾 120s 超时。
- **F8 占位符陷阱（判定错误即整篇空白）**：懒加载未触发的图是 `<img class="rich_pages wxw-img js_img_placeholder" src="data:image/svg+xml,...">`，此时 **`complete === true` 且 `naturalWidth === 1`**——用 `complete` 判「已加载」、用 `naturalWidth > 0` 判「有图」**都是错的**；判据必须 = **`naturalWidth > 1`** ＋ 占位符识别（class 含 `js_img_placeholder` / src 为 `data:`）。
- **F8 解法**：直接 `img.src = img.getAttribute('data-src')` **强制赋值**，绕过未被触发的 IntersectionObserver → 实测单篇 **15/15 图全部加载、空白 0px**（不滚动也生效）。
- **F9**：滚动预热**不可靠**——700px/180ms 慢滚到底仍停在占位符；滚动只作**背景图兜底**（CSS background-image 之类无 `data-src` 的资产），不作懒加载主手段。
- **F14 GIF**：GIF 同为 `data-src` 懒加载；强制加载后还须等 **1.5~2s 首帧解码**再截，否则截到空白/未渲染帧。
- **F15 物理切段须吸附图文空白带**：按 ≤~4600px 物理切段时硬切会把标题栏/产品卡**拦腰截断**；切点须吸附空白带——判据 = 灰度逐行亮度 ≥247 且连续 ≥12 行，搜索窗口 = 目标点 ±180px，**只向短方向吸附**（不为吸附把段拉长），终点 clamp 到文档高；无合格空白带时按原切点兜底。
- **工具面指针**：`cdp.js scroll-shot` 已内置懒加载 promote（`data-src` 强制赋值 + `naturalWidth>1` 判据）、物理切段与**切点吸附空白带（F15，V202610280004：DOM 法默认开 + `--snap-px` 像素兜底）**——判据/阈值/开关**以其 `--help` 为准**（含「不为吸附把段拉长」三条 clamp 硬约束，依据=本节 L77 实测记录）。
- 参考：1920 宽窗口下公众号正文栏仅约 677px 宽（观察性）——正文有效像素宽度受版式限制，属正常，不是截图失败。

### 日期规范化纪律（F18，他方 2026-10-23 实测）

> F18 = 同批第三轮复盘实测（他方会话）；我方尚未实弹复跑。

- **观察事实**：`#publish_time` 对**本年文章省略年份**（形如「9月16日」），且可用**相对日期**（形如「昨天 10:05」）——直接排序/比较会错，实测解析结果为「0年0月0日」。
- **入库前必须规范化**：
  - `^\d{1,2}月\d{1,2}日$` → 按抓取日所在年份补全为绝对日期；
  - `^(昨天|今天)\s*\d{1,2}:\d{2}$` → 按抓取日折算（昨天 = 抓取日 −1 天，今天 = 抓取日）。
- **纪律**：**规范化前不做日期比较**——排序/去重/时间窗筛选一律在规范化之后。
- 其他日期格式变体（带年份写法、纯时间戳等）待我方实弹验证。
